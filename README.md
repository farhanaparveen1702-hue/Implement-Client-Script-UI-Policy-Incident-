# Implement Client Script & UI Policy (Incident)

## Project overview
This folder contains example source files/documentation for a ServiceNow Incident form project using Client Scripts and UI Policies.

**Important:** ServiceNow Client Scripts and UI Policies are normally configured as records inside a ServiceNow instance. These files are source-code references for GitHub documentation; they do not automatically install the configuration into ServiceNow.

## Included examples
1. `client_script_onLoad.js` — example: make Short description mandatory when an Incident form loads.
2. `client_script_onChange.js` — example: show an informational message when Priority changes.
3. `ui_policy_documentation.md` — suggested UI Policy configuration and test cases.

## Before submitting
Compare these examples with the exact actions in your assigned project/demo. If your actual Client Script or UI Policy uses different conditions, replace these examples with your real configuration. Do not claim these example files are exported from your instance unless you created/exported them there.
